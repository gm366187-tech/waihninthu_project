PageSpeed / Lighthouse performance notes

1. The home-page LCP hero (h1.webp) is preloaded in <head> and uses fetchpriority="high".
2. The LCP image is NOT lazy-loaded.
3. Below-the-fold product images use loading="lazy" and decoding="async".
4. Images are converted/optimized to WebP.
5. JavaScript uses defer where applicable.
6. Google Maps iframe is lazy-loaded.

Important: Lighthouse's "Use efficient cache lifetimes" audit is largely controlled by HTTP cache headers. On GitHub Pages, these headers are managed by GitHub and cannot be fully fixed from HTML/CSS alone.

After uploading this version to GitHub Pages, wait for deployment to finish, hard-refresh, then run PageSpeed Insights again against the deployed URL.
